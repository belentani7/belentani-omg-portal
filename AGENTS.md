# Operating contract

- Treat the current repository, public catalog and documented decisions as the source of truth.
- Preserve the OMG Atlas visual language and project history.
- The 300 generative studies are artworks, not products, demos or repository records.
- Keep private repository names, descriptions, URLs, metrics and code out of all public output.
- Regenerate series HTML with scripts/generate-art-series.mjs; do not hand-edit generated pages.
- Keep catalog source data in data/catalog.js and public repository snapshots in data/repos.js.
- Use semantic HTML, keyboard navigation, accessible SVG labels, visible focus, sufficient contrast and reduced-motion support.
- Minimize GitHub Actions permissions, pin third-party actions to verified commit SHAs, and disable persisted checkout credentials.
- Run the repository tests and HTML parser before changing main. Report exact commit and deployment evidence.
